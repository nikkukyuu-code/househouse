ハウスハウス

リポジトリ内のフォルダ構成と、ゲームファイルの置き場所です。

ゲームを遊ぶ（game/）

本体は下の game/ フォルダにあります

フォルダ構成

nikkukyuu-code/househouse/ ├── index.html ← この説明ページ ├── README.md └── game/ ← ゲーム本体 ├── index.html 起動ファイル ├── css/ │ └── style.css └── js/ ├── game.js ├── house.js ├── net.js └── ui.js

ゲームファイルの場所

ブラウザで動かす本体はすべて game/ の中にあります。

  • game/index.html … ゲームの入口
  • game/css/ … 見た目
  • game/js/ … 対戦・家・通信・UI

ルートの index.html は説明専用で、ゲームのロジックは含みません。

URL

  • 説明ページ … /（いまのページ）
  • プレイ … /game/

更新するときは game/ 内のファイルを差し替えて main に push します。
