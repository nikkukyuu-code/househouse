ハウスと罠

自分の家に宝箱と爆弾・落とし穴を仕掛けて、相手の家から宝箱を探し合う対戦ゲームです。

スマホ向け・タッチ操作／COM対戦・ネット対戦あり

今すぐ遊ぶ

どんなゲーム？

お互いが3階建ての家を用意します。家のどこかに宝箱を1つ、相手を邪魔する爆弾や落とし穴を最大10個置けます。

試合が始まったら、相手の家に入って宝箱を探します。同時に、相手もあなたの家を探索しています。

勝ち方

  • 勝ち … 相手の家の宝箱に先に触れる
  • 勝ち … 爆弾・落とし穴で相手の体力（ハート10個）を0にする
  • 負け … 自分の宝箱を取られる／自分の体力が0になる

画面の見方

上半分 相手があなたの家を歩いている様子。自分が仕掛けた爆弾・落とし穴や宝箱が見えます。
下半分 あなたが相手の家を探索中。十字キーで移動。相手の爆弾・落とし穴は踏むまで見えません。

相手が爆弾や落とし穴に引っかかる瞬間を見られるのが、このゲームの面白さです。

はじめ方

  1. 1「COM対戦」なら一人で練習できます（おすすめ）
  2. 2家を設計：宝箱1つ＋罠最大10（爆弾／落とし穴）
  3. 3「準備完了」で対戦スタート
  4. 4ネット対戦は「ルームを作成」→ 6桁の数字を相手に伝える

操作・爆弾と落とし穴

  • 移動 … 画面右下の十字キー（タップ押しっぱなし可）
  • 階の移動 … 階段マスへ乗る（色で1F／2F／3Fが分かります）
  • 爆弾 … 踏むと爆発してハート1.5個分のダメージ（半ハート表示）
  • 落とし穴 … ダメージ＋下の階へ落ちる（1Fではダメージのみ）
