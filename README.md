# ハウスハウス

スマホ向けの2人対戦探索ゲームです。自分の家に宝箱と罠を仕掛け、相手の家から宝箱を探し合うか、罠で相手の体力をゼロにすると勝ちです。

**プレイ:** https://nikkukyuu-code.github.io/househouse/

## 遊び方

### COM対戦（オフライン・おすすめ）
1. タイトルで「COM対戦」をタップ
2. 自分の家を設計（宝箱1つ必須、罠は最大5つ）
3. 「準備完了」→ COMが自動で家を設計
4. 対戦開始
   - **上画面**: COMがあなたの家を探索（罠の作動が見える）
   - **下画面**: あなたがCOMの家を探索（画面右下の十字キーで移動）

### オンライン対戦（PeerJS）
1. ホストが「ルームを作成」→ 4文字コードを相手に伝える
2. ゲストが「ルームに参加」→ コード入力
3. 各自が家を設計して「準備完了」
4. 両方の準備が揃うと対戦開始

HTTPS（GitHub Pages）上でオンラインが使えます。PeerJS が読めない環境でも COM対戦・練習モードは動きます。

### 両方設計して練習
自分の家と「相手役の家」を両方自分で置き、その後 AI が上画面を動かす練習用モードです。

## 画面・操作
スクロールなしの固定ビューポート。十字キー（D-pad）で移動、セットアップはタップ配置。

## 勝利条件
- 相手の家の宝箱に触れる → 勝ち
- 相手の体力（ハート3つ）を罠で0にする → 勝ち

## 公開
GitHub Pages（`main` ブランチのルート）。更新は `gh` / Git でこのリポジトリに push するだけです。
