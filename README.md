# ハウスの罠（仮）

スマホ向けの2人対戦探索ゲームです。家に宝箱と爆弾・落とし穴を仕掛け、相手の家から宝箱を探します。

- **遊び方（説明ページ）:** https://nikkukyuu-code.github.io/househouse/
- **プレイ:** https://nikkukyuu-code.github.io/househouse/game/

## 遊び方（要点）

1. 自分の3階建ての家に宝箱1つと罠（爆弾／落とし穴、最大10）を置く
2. 対戦では上下分割：上＝相手があなたの家、下＝あなたが相手の家
3. 宝箱を先に見つけるか、罠で相手の体力を0にすると勝ち
4. オンラインのルームコードは6桁の数字／COM対戦あり
